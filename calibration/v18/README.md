# v18 레이더 최종값 보정

기준 버전은 v17.1 (d0791f75)이다. 보정 표본은 st8~12의 369채보다. 신·구 Overjoy 표에 등록된 MD5는 레벨에 관계없이 기준 집단과 2차 검증 집단에서 모두 제외했다. 게임에서 채보를 평가할 때는 같은 보정 함수를 쓴다.

## 보정과 적용 순서

1. 기존 식으로 일곱 축과 각 축의 지속 부담을 계산한다. DELAY를 비롯하여 다른 축의 계산에서 쓰는 NOTES는 이 단계의 원래 값을 사용한다.
2. 기존 STAMINA 집계 직전에 `applyFinalSkillRatings(out[notes], out[chord], out[peak])`를 한 번 호출한다. 런타임 실시간 계산과 내장 DB 생성에서 같은 함수를 사용한다.
3. 기존의 축별 지속 부담과 새 점수로 STAMINA를 다시 집계한다. 800 이상인 구형 STAMINA 값만 보고 새 STAMINA를 추정하면 원래의 기여 축을 복원할 수 없다. 기존 설치의 채보 레이팅 캐시 역시 새 버전으로 구분해야 한다.

800까지 최종 보정은 항등 함수다. 800 초과 구간에서 NOTES, CHORD, PEAK 각각의 표본 4위와 5위 사이를 1000에 대응시켰다. DELAY에서 1000 초과가 4/369였기 때문이다. 이후에는 각 축의 실측 최고점과 DELAY의 최고점을 3 대 7로 반영하되 상단 기울기를 4까지 허용했다. 관측 최댓값 이후에도 점수는 연속으로 증가한다. STAMINA는 기존의 지속 부담에 따라 여러 축에서 높은 값을 받을 수 있다. SCRATCH와 SOF-LAN은 전용 패턴의 분포가 다른 만큼 이번 일반 난이도표 통계만으로 올리지 않았다.

## 검증

- 2차 점검은 sl0~11, st0~12 중 Overjoy MD5를 제외한 4,807채보가 대상이며 그중 4,806채보를 계산했다. st6의 `Quadrupolar : :` (`bf2062b41a6f576d8d3e35049664a9c5`)는 점수 데이터가 없어 제외했다.
- 내장 6,700채보의 네 축 DELAY, JACK, SCRATCH, SOF-LAN은 이전 버전과 동일했다. STAMINA가 다른 일곱 축의 최대를 넘는 사례는 없었다.
- st8~12에서 한 축이라도 1000을 넘은 채보는 174개에서 17개가 됐다. 이때 한 채보에 여러 축이 겹쳐도 한 번만 센다. sl0~11은 2,391개 전부 8축 점수가 동일했다. st8~9에 남은 한 채보는 st9 アレア→イデア [プラズマ+]의 JACK 1035.13이다.
- 기준 집단을 MD5로 다섯 그룹으로 나눠, 네 그룹으로 보정 기준을 구하고 남은 한 그룹으로 확인했다. 이를 다섯 번 반복해 합친 1000 초과 건수는 NOTES 5, PEAK 6, CHORD 6, DELAY 4, JACK 4, STAMINA 9였다. 전체 표본에 맞춘 세 축의 4개라는 숫자는 이 독립 점검의 결과와 구분한다.

`st8-12.csv`의 최댓값은 보정 후 열만 정수로 반올림했다. `levels.csv`는 레벨별 표본 수와 1000을 엄격히 초과한 채보 수, 채보마다 가장 높은 축을 고른 뒤 구한 중앙값, DELAY의 중앙값과 최고점을 담았다. 레벨별 중앙값에는 0인 축도 그대로 포함했다. 세부 패턴이 드문 레벨에서 특정 축의 중앙값이 앞 레벨보다 낮아질 수 있다.
